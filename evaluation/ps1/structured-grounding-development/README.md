# General grounding development cases

These three questions are development diagnostics based on the supplied NIT Goa PDF and revealed failure categories. They are not held-out questions, approved relevance labels or an accuracy benchmark. `labels_verified` remains false; empty source groups are not gold labels.

The questions exercise full Attendance B11.4, two-part fee/deadline coverage and the scope difference between general registration and returning after discontinuation. No policy answers are hardcoded into the application. Synthetic unit tests exercise other institutions' hypothetical wording separately and never index it as real policy.
